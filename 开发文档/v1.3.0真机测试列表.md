# v1.3.0 真机测试列表（配置管理体验重构与备份体系）

> 分支：`feature/config-manager-overhaul` ｜ 测试环境：Windows + Blender 5.1.0（另需 5.2/5.3 任意一个作为迁移目标）
> 前置：先安装/启用本插件（mmy_pack_config），打开顶部菜单栏「配置管理」
> 标记说明：🔴 关键路径（必须通过）｜🟡 重要 ｜🟢 边界/异常

## 一、主面板（P0）

| # | 级别 | 操作 | 预期 |
|---|------|------|------|
| 1.1 | 🔴 | 顶部菜单点「配置管理」 | 弹窗顶部状态区显示：当前 Blender 版本 + Portable/普通安装、备份目录、（如有）上次迁移结果 |
| 1.2 | 🔴 | 观察弹窗底部按钮 | 按钮文案为「关闭」而非「确定」；点「关闭」只关弹窗、无任何操作发生 |
| 1.3 | 🟡 | 查看分区 | 三个分区：备份（立即备份/备份记录）、迁移（迁移到新版/导出配置包，注明"仅同主版本、仅升级"）、维护（打开报告/清理迁移残留） |
| 1.4 | 🟢 | 从未迁移过的干净环境打开面板 | 不显示"上次迁移"行；「打开报告」按钮置灰不可点 |

## 三、迁移：预检确认页（P0：M1/M2/M4）

| 3.2 | 🔴 | 预检确认页内容 | 显示：源版本、迁移组件、输出目录与可用空间、目标版本/用户目录/已有配置大小、"迁移前自动备份"提示 |

## 已知限制（不属于缺陷）

- 跨主版本（4.5 → 5.1）与降级（5.2 → 5.1）迁移**按设计拒绝**；降级请走「备份记录 → 解压恢复」
- 仅支持 Windows；进程检测依赖 PowerShell（企业策略禁用时迁移会报错提示）
- 附加目标的版本号显示来自安装目录名启发式解析，以预检探针返回的真实版本为准
