# 打包路径记忆预设持久化方案

## 项目概述

打包导出功能需要记住上次使用的 `portable` 文件夹和输出目录。原实现主要依赖 `AddonPreferences` 与项目根目录的 `.pack_config.json`，插件更新或重新安装后容易丢失路径记忆。

## 技术架构

新增 `mmy_pack_config/path_memory.py` 作为路径记忆模块，使用 Blender 用户脚本预设目录保存 JSON：

```text
scripts/presets/mmy_blender_configure/path_memory.json
```

在 Portable 模式下，该路径位于：

```text
portable/scripts/presets/mmy_blender_configure/path_memory.json
```

## 模块划分

| 模块 | 职责 |
|------|------|
| `path_memory.py` | 读取、写入、应用路径记忆预设 |
| `preferences.py` | 路径属性变化时同步写入 presets，并在注册时恢复 |
| `ui.py` | 打包弹窗执行后保存 Portable 路径和输出目录 |
