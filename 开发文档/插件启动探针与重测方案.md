# 插件启动探针与重测方案

## 项目概述

插件加载耗时监控当前通过 monkey-patch `bpy.utils._addon_utils.enable` 采集插件启用耗时。由于监控插件自身也需要被 Blender 加载，注入时机可能晚于部分插件，导致这些插件只能显示为“早期加载”，无法获取真实耗时。

本次需求新增两类能力：

1. 启动探针模式：安装一个轻量 startup 脚本，在下次 Blender 启动早期注入计时逻辑。
2. 手动重测：在偏好设置面板中一键重测插件，支持重测列表中选择的插件。

## 技术架构

### 启动探针

- 由 `mmy_pack_config/addon_timer.py` 生成 startup 脚本。
- 脚本安装到 `bpy.utils.user_resource('SCRIPTS', path='startup', create=True)` 返回目录。
- startup 脚本尽早 patch `bpy.utils._addon_utils.enable`，记录插件启用耗时。
- 结果写入项目同级 JSON 文件，插件面板在后续启动时读取并展示。

### 手动重测

- 通过 `addon_utils.disable()` 和 `addon_utils.enable()` 自动执行一次重新启用。
- 重测前清理目标插件主模块及其子模块的 `sys.modules`，尽量接近重新导入成本。
- 重测结果记录到当前会话数据，并立即保存。
- 默认只重测用户选择的单个插件，避免批量重测破坏复杂插件运行状态。

## 模块划分

| 模块 | 责任 |
|------|------|
| `addon_timer.py` | 探针安装/卸载/读取、手动重测、记录合并 |
| `preferences.py` | UI 控件、插件选择、操作按钮、结果展示 |
| `__init__.py` | 启动时读取历史与探针数据 |
