# 插件加载耗时监控优化记录

## 背景

在 v1.1.1 之后的迭代中，对插件加载耗时监控模块做了三轮优化：可关闭的监控开关、异步写盘避免 UI 卡顿、启动探针 `register` 函数补全。本文记录这三个问题的根因与处理经验，供后续维护参考。

## 问题 1：监控开关缺失导致强制注入与启动开销

### 现象

旧 `register()` 先调用 `addon_timer.manager.begin_session() / load_data() / load_probe_data() / patch() / register_fallback()`，再注册 UI 与偏好设置。结果有两个问题：

- 监控逻辑在偏好设置可用之前就运行，无法读取「是否启用监控」的开关；
- 无论用户是否需要耗时数据，每次启动都强制 monkey-patch 并注册 2 秒延迟扫描，带来固定启动开销。

### 处理

调整 `register()` 执行顺序：

1. 先 `preferences.register()` / `ui.register()` / `auto_pack.register()`，保证能读到开关；
2. 再读取 `prefs.enable_load_monitoring`；
3. 仅当开关打开才执行 `begin_session / load_data / load_probe_data / patch / register_fallback`。

关闭监控时完全跳过计时相关代码路径，实现「零启动负担」。偏好设置面板中同步显示「监控已关闭：本次启动未采集数据」提示。

### 经验

- 插件自身的 `register()` 顺序很关键：有依赖顺序的模块要先注册被依赖方。
- 把「可选功能」用偏好开关与「强制功能」解耦，避免对不需要该功能的用户造成额外开销。
- 涉及重新读取 `bpy.context.preferences.addons` 的开关，一定要在偏好设置注册之后再读取。

## 问题 2：fallback 扫描主线程写盘造成 UI 卡顿

### 现象

2 秒后的 fallback 扫描在 Blender timer 回调中执行，而 timer 回调本质运行在主线程。`save_data()` 在其中同步 `json.dump` 写盘，文件较大或磁盘较慢时会出现可见的界面卡顿 / 掉帧。

### 处理

- `save_data(background=False)` 新增 `background` 参数；
- 主线程先 `asdict` 快照 `self.records` 为 `data`，再交给守护线程 `_write()` 写盘，避免后台线程与同步写盘并发修改 `self.records`；
- 用模块级 `_SAVE_LOCK`（`threading.Lock`）保护文件写入，防止并发写坏 JSON；
- 若守护线程启动失败（极少见），回退为同步写盘，保证数据不丢。

### 经验

- Blender 的 `bpy.app.timers` 回调运行在主线程，任何耗时 IO 都必须异步化，否则直接卡 UI。
- 多线程共享文件：先在主线程快照数据，再移交后台线程；并用锁保护磁盘写入。
- 异步写盘要有「回退同步」兜底，避免线程异常导致数据丢失。

## 问题 3：启动探针报 "has no register function" 警告

### 现象

放入 Blender `startup` 目录的探针脚本，被 Blender 启动脚本加载器检查 `register` 函数；脚本若只通过 `_install()` 在导入时完成逻辑、未定义 `register` / `unregister`，会在控制台打印 `has no register function` 警告。

### 处理

在探针脚本末尾补上空的 `register()` / `unregister()`：

```python
def register():
    # 空 register/unregister：Blender 启动脚本加载器会对 startup 目录下的脚本
    # 检查 register 函数，缺失会报 "has no register function" 警告。
    # 实际计时逻辑已在模块导入时通过 _install() 完成，此处仅用于消除警告。
    pass


def unregister():
    pass
```

实际计时逻辑仍在模块导入时通过 `_install()` 完成，空函数仅用于满足加载器约定、消除警告。

### 经验

- Blender 对 `startup` 目录下的脚本有「必须提供 register/unregister」的约定，缺失会告警。
- 逻辑在导入期已完成、无需运行时注册时，补空函数即可静默加载，不影响功能。

## 变更记录
