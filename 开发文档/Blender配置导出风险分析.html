config/userpref.blend

Blender 核心配置文件，包含所有用户偏好设置

  • 软件设置：界面主题、编辑器偏好、系统设置
  • 快捷键映射：所有自定义快捷键
  • 插件状态：已启用插件的列表
  • 路径设置：渲染输出、临时文件、资产库路径
风险维度评估说明
版本兼容中风险Blender 会自动转换，但新版本设置可能丢失
跨机识别低风险所有 Blender 都能识别此文件
快捷键高风险不同版本快捷键系统可能重构（如 4.0 大改）
startup.blend 必须导出
config/startup.blend

默认场景和界面布局模板

  • 默认场景：新建文件时的初始状态
  • 界面布局：窗口分割、编辑器位置
  • 默认对象：摄像机、灯光等初始设置
风险维度评估说明
版本兼容中风险场景数据格式相对稳定，但新功能可能丢失
跨机识别低风险所有 Blender 都能识别此文件
与 userpref 区别低风险独立文件，可单独替换不影响偏好
插件 (addons) 推荐导出
scripts/addons/

用户安装的第三方插件目录

  • 单文件插件：.py 文件
  • 多文件插件：包含 __init__.py 的目录
  • 启用状态已记录在 userpref.blend
风险维度评估说明
版本兼容高风险插件可能依赖特定 Blender API 版本
跨机识别低风险放入 addons 目录即可被识别
API 变更禁止某些插件在跨版本时会报错或崩溃
用户配置 (config) 可选导出

  • recent-files.txt：最近打开的文件列表

用户保存的操作预设

  • 渲染预设：渲染设置快照
  • 修改器预设：修改器参数配置
  • 操作预设：各类操作的参数模板
风险维度评估说明
版本兼容中风险新版本可能新增/删除参数，旧预设可能不完整
跨机识别低风险预设系统稳定，格式兼容
功能变更中风险如渲染引擎重构，预设参数可能失效
启动脚本 (startup) 谨慎导出

Blender 启动时自动执行的 Python 脚本

  • 自动化脚本：自定义初始化逻辑

风险维度评估说明
版本兼容禁止API 变更可能导致脚本报错甚至崩溃
跨机识别低风险放入 startup 目录自动执行
安全风险高风险恶意脚本可能在启动时执行危险操作

💡 导出配置建议

同版本迁移（推荐）
导出全部配置项，风险最低。适合多台电脑同步或备份。
升级迁移（谨慎）
导出 userpref.blend + startup.blend + config + presets。插件需逐个测试，startup 脚本需适配 API。
降级迁移（不建议）
仅导出 config。userpref.blend 可能无法读取，插件大概率不兼容。
跨主版本迁移（禁止）
如 3.x → 4.x，应重新配置。强行迁移会导致崩溃或功能异常。

❓ 常见问题解答

Q1: userpref.blend 和 startup.blend 有什么区别？
文件内容用途
startup.blend默认场景和界面布局新建文件时的初始状态
userpref.blend用户偏好、插件状态、快捷键全局配置

两个文件都在 Blender 启动时加载，startup.blend 定义初始场景，userpref.blend 定义全局偏好。

Q2: 如何实现便携式/便携模式？
在 Blender 可执行文件所在目录创建 portable 文件夹，Blender 会将所有配置、插件、预设保存在该文件夹中。
  • 适合 U 盘携带或云同步
  • 配置与安装位置绑定，便于迁移
  • 结构：portable/4.5/config/、portable/4.5/scripts/
Q3: 插件启用状态存储在哪？
插件启用状态存储在 userpref.blend 中。导入 userpref.blend 会自动恢复插件启用状态，但插件文件本身需要从 addons 目录还原。
Q4: 如何手动导出快捷键？
  • 界面操作：Edit → Preferences → Keymap → Export
  • 保存为 .py 文件
  • 导入时使用同一位置的 Import 按钮
Q5: 版本升级时如何迁移插件？
  • 安装新版本 Blender 时勾选 "Import Blender Preferences"
  • 手动复制 scripts/addons 目录到新版本
  • 检查插件是否兼容新版本 API
  • 主版本号变化（如 3.x → 4.x）可能导致插件不兼容
Q6: Python 如何保存用户偏好？
# 方法 1: 使用 Operator（推荐） bpy.ops.wm.save_userpref() # 方法 2: 设置自动保存标志 bpy.context.preferences.use_preferences_save = True # 方法 3: 修改插件偏好后保存 addon_prefs = bpy.context.preferences.addons[__package__].preferences addon_prefs.some_property = "new value" bpy.ops.wm.save_userpref()

🐍 Python API 关键参考

配置目录获取

import bpy from pathlib import Path # 配置目录（userpref.blend、startup.blend 所在） config_dir = Path(bpy.utils.user_resource('CONFIG')) # 脚本目录（addons/presets/startup 的父目录） scripts_dir = Path(bpy.utils.user_resource('SCRIPTS')) # 数据文件目录（笔刷、贴图、资产） datafiles_dir = Path(bpy.utils.user_resource('DATAFILES')) # 扩展目录（Blender 4.5+） extensions_dir = Path(bpy.utils.user_resource('EXTENSIONS')) # 直接获取插件目录 addons_dir = Path(bpy.utils.user_resource('SCRIPTS', path='addons'))

偏好设置操作

# 保存用户偏好 bpy.ops.wm.save_userpref() # 获取偏好对象 prefs = bpy.context.preferences # 系统偏好 system_prefs = prefs.system # 视图偏好 view_prefs = prefs.view view_prefs.ui_scale = 1.2 # 设置界面缩放 # 文件路径偏好 filepaths_prefs = prefs.filepaths # 获取已启用的插件列表 enabled_addons = list(bpy.context.preferences.addons.keys())
