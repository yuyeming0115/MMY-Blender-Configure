Blender 配置导出风险分析

全面掌握配置迁移的风险点与最佳实践

风险等级定义

低风险 跨版本通用，直接迁移
中风险 需验证，可能有小差异
高风险 版本差异大，需适配
禁止 跨版本迁移会崩溃

配置项详解

Blender 配置目录下的各文件和文件夹的风险评估

userpref.blend 必须导出
config/userpref.blend

Blender 核心配置文件，包含所有用户偏好设置

  • 软件设置：界面主题、编辑器偏好
  • 快捷键映射：所有自定义快捷键
  • 插件状态：已启用插件的列表
版本兼容中风险
快捷键高风险
startup.blend 必须导出
config/startup.blend

默认场景和界面布局模板

  • 新建文件时的初始状态
  • 窗口分割、编辑器位置
  • 与 userpref.blend 独立存储
版本兼容中风险
跨机识别低风险
插件 (addons) 推荐导出
scripts/addons/

用户安装的第三方插件目录

  • 单文件插件：.py 文件
  • 多文件插件：包含 __init__.py 的目录
  • 启用状态记录在 userpref.blend
版本兼容高风险
API 变更禁止
预设 (presets) 推荐导出
scripts/presets/

用户保存的操作预设

  • 渲染预设：渲染设置快照
  • 修改器预设：修改器参数配置
  • 操作预设：各类操作参数模板
版本兼容中风险
跨机识别低风险
用户配置 (config) 可选导出
config/bookmarks.txt, recent-files.txt

用户操作历史和书签记录

  • 文件浏览器书签
  • 最近打开的文件列表
版本兼容低风险
路径问题中风险
启动脚本 (startup) 谨慎导出
scripts/startup/

Blender 启动时自动执行的脚本

  • 自动化脚本：自定义初始化
  • 环境配置：设置变量、加载模块
版本兼容禁止
安全风险高风险
数据文件 (datafiles) 可选导出
datafiles/

用户自定义的数据资源

  • 笔刷：自定义雕刻/绘画笔刷
  • 资产库：本地资产定义
版本兼容中风险
路径依赖中风险
扩展 (extensions) 谨慎导出
extensions/ (Blender 4.5+)

Blender 4.5+ 新增的官方扩展系统

  • 官方扩展：通过扩展平台安装
  • 仅 4.5+ 存在此系统
版本兼容禁止
跨机识别低风险 (同版本)

重大版本变更风险点

版本重大变更影响配置风险
4.0 → 4.1 快捷键系统重构 keymap 高风险
3.x → 4.0 节点系统大改、EEVEE 重构 presets, datafiles 禁止
4.4 → 4.5 新增扩展系统 (extensions) extensions 中风险
2.x → 3.x 工作区、节点重构 userpref.blend 禁止

导出配置建议

同版本迁移（推荐）
导出全部配置项，风险最低。适合多台电脑同步或备份。
升级迁移（谨慎）
导出 userpref.blend + startup.blend + config + presets。插件需逐个测试。
降级迁移（不建议）
仅导出 config。userpref.blend 可能无法读取，插件不兼容。
跨主版本迁移（禁止）
如 3.x → 4.x，应重新配置。强行迁移会导致崩溃。

常见问题

Q: userpref.blend 和 startup.blend 有什么区别？
startup.blend 定义新建文件时的初始场景和界面布局，userpref.blend 存储全局偏好设置、插件状态、快捷键。两者独立，可单独替换。
Q: 如何实现便携式模式？
在 Blender 可执行文件所在目录创建 portable 文件夹，Blender 会将所有配置保存在该文件夹中，适合 U 盘携带或云同步。
Q: 插件启用状态存储在哪？
存储在 userpref.blend 中。导入 userpref.blend 会自动恢复插件启用状态，但插件文件本身需从 addons 目录还原。
Q: 如何手动导出快捷键？
Edit → Preferences → Keymap → Export，保存为 .py 文件。导入时使用 Import 按钮。
