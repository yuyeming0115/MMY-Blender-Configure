# 每周自动打包方案

## 项目概述

新增每周一自动打包功能，用于将上次选择的 Blender `portable/` 文件夹自动打包为 zip，并输出到上次设置的打包输出目录。

## 技术架构

- 使用 `bpy.app.timers` 注册轻量定时检查。
- 每小时检查一次是否满足触发条件。
- 满足条件后启动 `pack_script.py` 子进程执行打包，避免阻塞 Blender UI。
- 使用状态文件记录本周是否已自动打包，防止周一重复触发。

## 模块划分

| 模块 | 责任 |
|------|------|
| `auto_pack.py` | 自动打包调度、状态记录、子进程启动 |
| `preferences.py` | 自动打包开关与立即测试按钮 |
| `__init__.py` | 注册与注销自动打包定时器 |

## 触发规则

1. 用户启用“每周一自动打包”。
2. 已保存有效的 `上次 Portable 路径`。
3. 已保存有效的 `打包输出目录`。
4. 当前日期为周一。
5. 当前 ISO 周尚未自动打包过。
