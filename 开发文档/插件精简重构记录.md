## 背景

用户核心需求变更：从「精细化备份/导入/导出配置」变为「直接打包整个 Blender `portable/` 文件夹」。

原有插件的备份/导入/书签系统完全冗余，需要大幅精简。

## 变更内容

### 1. 重构 `pack.py`（由 74 行扩展为 ~250 行）

| 功能 | 实现方式 |
|------|------------|
| 动态路径选择 | `tkinter.filedialog.askdirectory` 选择 `portable/` 文件夹 |
| 自动版本检测 | 三层方案：父目录名 → 子目录名 → 手动输入 |
| 时间戳命名 | `datetime.now().strftime("%Y%m%d_%H%M")` |
| 自动重命名 | 文件存在时自动加 `(1)`, `(2)` 后缀 |
| 输出路径记忆 | `.pack_config.json` 记住上次输出目录 |
| 版本号命名 | `Blender_Portable_v{version}_{timestamp}.zip` |

### 2. 精简插件模块

| 文件 | 行数变化 | 操作 | 原因 |
|------|-----------|------|------|
| `operators.py` | 143 → 0 | **删除** | 备份/导出/导入已被 `pack.py` 替代 |
| `ui.py` | 297 → 0 | **删除** | 完整配置面板 UI 已被 `pack.py` 替代 |
| `preferences.py` | 84 → ~70 | **精简** | 删除 7个 `include_*` + 书签系统，保留耗时监控显示 + `pack_output_path` |

**净删除**：~880 行（原 ~924 行 → 现 ~44 行）

### 3. 修复 `addon_timer.py` 的 ERROR 问题

**原因**：
- `dataclasses` 拼写错误（应为 `dataclasses`）
- `record()` 调用缺逗号：`AddonLoadRecord(name elapsed, error)` → `AddonLoadRecord(name, elapsed, error)`
- 错误判断过宽：`if not mod or err` 把返回 `None` 的正常插件也记为 ERROR

**修复**：
- 拼写修正
- 补上逗号
- 错误判断改为 `if err:`（只在有异常时记 ERROR）

## 新工作流程

### 打包 `portable/` 文件夹

```bash
# 在项目目录运行
python pack.py
```

交互流程：
1. 弹出文件夹选择对话框 → 选择 `portable/` 文件夹
2. 自动检测 Blender 版本号（或手动输入）
3. 弹出文件保存对话框 → 选择输出路径（默认上次路径）
4. 打包完成，弹出提示

### 设置默认输出目录

在 Blender 中：
1. 编辑 → 偏好设置 → 插件 → MMY Blender Configure
2. 设置「打包输出目录」
3. 下次运行 `pack.py` 时自动填入该路径
